Privacy Policy

Effective date: October 8, 2026

Deadline tracking works locally without an account. Optional conference-star sync uses GitHub sign-in on ccfddl.com.

Local Storage

Deadlines, imported conference entries that you save, and interface preferences are stored in chrome.storage.local within the browser profile where the extension runs. Optional sync also stores the GitHub login, pending conference IDs, excluded stages and sync status locally.

External Data Sources

The extension requests the CCFDDL dataset and fallback ICS feeds over HTTPS when you use conference import. These requests populate the import list. If you enable star sync, the extension uses a signed-in ccfddl.com tab to read your account login and conference stars, send conference-star changes, and fetch conference dates. It never reads or stores GitHub tokens; manual deadlines are not uploaded.

Your Sync Choices

Sync is off until you connect it. You can disconnect in Settings at any time. Disconnecting retains local deadlines and existing website stars, clears the extension’s sync account/state and cancels pending sync operations. It does not delete your CCFDDL account or sign you out of the website. Website stars and GitHub sign-in are handled by those services under their own policies.

Analytics

The extension has no project-hosted analytics or telemetry. Core deadline tracking works without an account. Optional star sync communicates with ccfddl.com using your website session.

Third-Party Links

The extension and this website may link to third-party sites such as conference homepages, GitHub repositories, or the Chrome Web Store. Those services have their own privacy policies and terms.

Changes

If this policy changes, the updated version will be published on this page.
