FAQ

Where are my deadlines stored?

Deadlines and preferences are stored in chrome.storage.local. In v2.6, you can optionally sync conference stars through a signed-in ccfddl.com tab. Manual deadlines remain local.

Where do imported conferences come from?

Imports use the CCFDDL dataset served over direct HTTPS. The data comes from the upstream ccfddl/ccf-deadlines project. If that source fails, the Chinese and English ICS feeds can recover independently; each request and response read is limited to 10 seconds.

Should I trust imported deadlines without checking?

No. Imported dates are a convenience feature. For any real submission, always confirm the current CFP and official deadline on the conference website.

Does the extension collect analytics or telemetry?

No project-hosted telemetry is built into the extension. The workflow is designed to be local-first and does not require logging in.

Can I open the official conference homepage from a card?

Yes. Click the title of an imported conference to open its official site. The chevron expands its deadlines.

Can I use my own custom deadlines?

Yes. The extension supports both manually added deadlines and imported conference entries.

How do I add a deadline to my calendar?

Right-click a card for its next deadline, or expand the conference and use a specific stage’s calendar icon. Export to Google Calendar or download ICS for Apple / iCloud and other calendar apps.

How do I connect my GitHub login and website stars?

Click the account icon beside My DDLs, then sign in with GitHub on ccfddl.com if needed. Keep the website tab open for automatic sync. This syncs conference stars on CCFDDL, not GitHub repository stars. No token entry is needed. Disconnect in Settings.

Why are several deadlines combined into one card?

Dates with the same conference edition ID share one card. Its next deadline is visible by default; expand it for the other stages and rounds. Each stage has its own calendar action. A website star represents the whole edition.

What if adding or deleting a conference fails after upgrading?

An unpacked extension can show updated popup files while still running its old background worker. Reload the extension from its recovery button or the browser’s extension manager, then reopen the popup. v2.6 distinguishes a missing background from a failed save or read. For an uncertain save, refresh the list before repeating the action. Existing saved data is not automatically cleared.

How often does the toolbar badge update?

The badge recalculates after saved deadlines change and schedules its next update when the day count changes or a deadline expires. Optional website-star sync runs separately, about once a minute while the browser can run it, and after local edits.

What if the popup gets stuck or does not open?

If a local read fails or takes more than 3 seconds, click Retry. If the popup does not appear at all, right-click the extension icon and choose Options to use the tracker in a tab. Record browser and extension versions and console errors if it recurs. This is separate from the v2.6 save-error recovery.
