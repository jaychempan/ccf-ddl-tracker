# CCF DDL Tracker v2.6.0

2026-10-08 · Manifest `2.6.0` · Popup `v2.6`

## 中文

- 新增通过网站 GitHub 登录连接的可选 CCFDDL 会议收藏同步。在“我的截止日期”旁点击小账号图标即可连接，此后自动同步，原有刷新按钮也会刷新收藏。
- 按会议届次合并截止日期，卡片默认展示最近节点，展开查看阶段和轮次；一条导入结果即可添加该届可用日期。
- 各阶段支持单独添加日历和移除，也可移除整届会议。开启同步后，删除最后一个已保存节点或整届会议会取消网站收藏。
- 解析会议时保留源时区及阶段信息，正确处理位于时间线之后的时区与地点字段。
- 本地写入与同步提交排队执行，保留离线操作，防止切换账号和过时响应覆盖数据；手动 DDL 保留在本地，无需填写 GitHub Token 或增加扩展权限。
- 修复将保存失败和后台连接失败误报为本地读取失败的问题。后台未连接时可重新加载扩展；保存结果不确定时先刷新列表再重试。
- 同步更新中英文网站、指南、隐私说明和版本预览，补充弹窗与同步回归测试，并在浏览器中验证升级恢复及数据保留。

### 升级

更新原 `chrome/` 目录，在浏览器扩展管理页重新加载原安装项，再打开弹窗确认 v2.6。保留原安装项以保留本地数据；刷新已有 ccfddl.com 标签页后再连接收藏。旧版及 ICS 条目缺少届次 ID 时仍保留在本地，从当前导入列表重新添加会议可关联同步。

### 收藏同步

点击“我的截止日期”旁的小账号图标，按需在网站使用 GitHub 登录，并保留网站标签页。首次连接合并双方收藏；手动 DDL 不上传。此功能同步 CCFDDL 会议收藏，不是 GitHub 仓库 Star。移除整届或最后一个节点会取消网站收藏。在设置中断开连接会保留两端数据，并取消待同步操作。

## English

- Added opt-in CCFDDL conference-star sync through the website’s GitHub login. Connect from the small account icon beside My DDLs; subsequent sync is automatic and the existing refresh button also refreshes stars.
- Merged deadlines by conference edition into compact cards. Show the next deadline first, expand stages and rounds, and add all available dates from one import result.
- Added calendar and removal actions per stage, plus whole-conference removal. With sync enabled, removing the final saved stage or the whole conference also removes its website star.
- Preserved source time zones and stage metadata when parsing conference editions, including fields declared after the timeline.
- Serialized local writes and sync commits, retained offline changes, guarded account switches and stale responses, and kept manual deadlines local. No GitHub token entry or additional extension permissions are required.
- Fixed save and background-connection errors being reported as local-read failures. Added extension reload for an unavailable background and list refresh before retrying an uncertain save.
- Updated the bilingual website, guides, privacy policy and release preview. Expanded popup and sync regression coverage, including browser checks for upgrade recovery and retained data.

### Upgrade

Update the same `chrome/` directory and reload the existing installation in the browser’s extension manager. Reopen the popup and check for v2.6. Keeping the existing installation retains local data. Refresh already-open ccfddl.com tabs before connecting stars. Older and ICS imports without edition IDs remain local; re-add a conference from the current import list to link it.

### Star sync

Click the small account icon beside My DDLs, sign in with GitHub on the website if needed, and keep its tab open. The first connection merges both sets of stars. Manual deadlines stay local. This syncs CCFDDL conference stars, not GitHub repository stars. Removing a whole edition or its last saved stage also unstars it. Disconnecting in Settings keeps data on both sides and cancels pending operations.

Output / 输出：`dist/ccf-ddl-tracker-v2.6.0.zip`。

After editing website translations or behavior, refresh the script URLs before running release checks. The content hash prevents cached translations from being mixed with a newer page. / 修改网站翻译或脚本后，先更新脚本 URL 再执行发布检查；内容哈希可避免旧翻译缓存与新页面混用。

GitHub Pages publishes the `website/` directory when its changes reach `main`. Chrome Web Store distribution requires a separate package submission and review. / 网站在相关改动推送至 `main` 后由 GitHub Pages 发布；Chrome 应用商店需单独提交安装包并审核。
